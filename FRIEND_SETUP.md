# Maelstrom Tech — прямое обновление из Prism, без Git

Репозиторий публичный. Git, приглашение в GitHub и папка C:\MaelstromPack другу не нужны.
Установленная предстартовая команда прямого packwiz остаётся прежней:
```
"$INST_JAVA" -jar packwiz-installer-bootstrap.jar https://raw.githubusercontent.com/DeepWhirepool/maelstrom-tech-pack/main/pack.toml
```
Bootstrap лежит в папке minecraft инстанса. Для новой установки: Prism, Minecraft 1.21.1, NeoForge 21.1.265; bootstrap взять с https://github.com/packwiz/packwiz-installer-bootstrap/releases и положить туда. Команду указать в настройках инстанса → Пользовательские команды → Перед запуском. Эта инструкция не требует менять существующую рабочую команду.

## Однократный переход со старого выпуска
Если установленный через packwiz выпуск был 0.1.15 или старше, либо его версия неизвестна, перед первым обновлением сохранить перечисленные ниже существующие файлы/папки ВНЕ инстанса:
- config/jei/
- config/inventoryprofilesnext/
- config/xaero/
- config/iris.properties, config/iris-excluded.json
- config/dynamic_fps.json, config/sodium-options.json (если есть).

В 0.1.15 в индексе было 49 личных файлов из этих групп (sodium-options в том снимке отсутствовал). Они удалены из управления начиная с 0.1.16. Прямой bootstrap удаляет ранее управляемый файл даже после локального изменения; update.ps1 здесь НЕ участвует и не защищает настройки.
1. Штатно закрыть мир/остановить хост. Отдельно скопировать всю папку мира вместе с playerdata/FTB team/quest data. Открытый мир не копировать.
2. Сделать внешнюю копию перечисленных настроек. Не удалять `packwiz.json` (локальный manifest bootstrap): это потеряет сведения об управляемых файлах.
3. Выполнить одно обновление bootstrap отдельно, без запуска Minecraft, в папке minecraft инстанса. В PowerShell, подставив путь к Java 21 из Prism:
   ```powershell
   & 'C:\путь-к-Java-21\bin\java.exe' -Djava.awt.headless=true -jar .\packwiz-installer-bootstrap.jar -g https://raw.githubusercontent.com/DeepWhirepool/maelstrom-tech-pack/main/pack.toml
   ```
4. При успешном завершении восстановить сохранённые личные настройки по прежним путям; затем запустить Prism обычным способом. Теперь они не управляются новым индексом и следующее обновление их не удаляет. При ошибке сохранить копию и текст ошибки, игру не запускать до разбора.

Если переход на 0.1.16/0.1.17 уже завершён и личные настройки сохранены/восстановлены, для следующего выпуска достаточно обычного перезапуска сборки с прежней предстартовой командой. Если старый переход уже удалил настройки, восстановить их можно только из своей копии; новый выпуск не восстанавливает неизвестные настройки автоматически.

Новый индекс исключает личные группы, миры, options.txt, аккаунты и логи. В изолированном headless-тесте настоящего bootstrap подтверждены удаление изменённого ранее управляемого файла и сохранность восстановленного файла при следующем обновлении; неуправляемые options/файл тестового мира сохранились. Это не тест на компьютере друга и не проверка подключения через e4mc.
Официальная схема прямой установки: https://packwiz.infra.link/tutorials/installing/packwiz-installer/ . При ошибке загрузки packwiz запуск игры следует прервать и сохранить сообщение ошибки.
